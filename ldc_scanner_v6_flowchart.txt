--------------------------------------------------------------------
1. WHAT THE PROGRAM DOES
--------------------------------------------------------------------
LDC SCANNER V6 is a real-time PyQt / pyqtgraph desktop GUI for an eddy-current
scanner robot. It reads sensor telemetry over a serial port (or replays a
recorded CSV as if it were live), streams it into three live plots, optionally
logs every sample to CSV, offers a two-way serial command console, and can
export the plots as journal-quality PDFs ("Snapshot").

The three live plots:
  - A 3D "surface curtain" of the trajectory (Time vs R_p vs L).
  - An upper-right plot that toggles between Phase Space (L vs R_p) and
    Time Trace (L vs t).
  - A crack-event plot (event magnitude or crack_size vs time).

Sensor naming convention used everywhere: sensor1 = R_p (resistance),
sensor2 = L (inductance).

--------------------------------------------------------------------
2. ARCHITECTURE IN ONE SENTENCE
--------------------------------------------------------------------
The Qt-free backend lives in the `scanner/` Python package (pure logic, data
classes, I/O sources, PDF export); the single runnable entry file
`LDC SCANNER V6.py` builds the Qt UI, owns the 50 ms redraw loop `update()`,
and wires all event handlers. You launch `LDC SCANNER V6.py` directly from the
repo root so that `import scanner` resolves.

Each entry: MODULE — role — key symbols — what it imports.

[A] scanner/config.py
    Role: single place for all runtime constants + a line-width helper.

    Imports: nothing (standard library only).
    NOTE: This is separate from the repo-root config.py (which configures the
      offline SNR/Scanimator analysis pipeline). Do not conflate them.

[B] scanner/parsing.py
    Role: pure functions that turn a received telemetry line into numbers.
    Key symbols: parse_keyed_fields(), parse_serial_line(),
      extract_reject_reason(), parse_crack_event().
    Imports: numpy.

[C] scanner/surface.py
    Role: pure geometry for the 3D ribbon "curtain" mesh + an R_p usability test.
    Key symbols: has_usable_rp(), build_surface_data() (returns

[D] scanner/widgets.py
    Role: the one custom pyqtgraph widget.
    Key symbols: ToggleAxisItem (a pg.AxisItem that emits `toggled` on click).

[E] scanner/csv_logger.py
    Role: owns the append-only output CSV file.
    Key symbols: CsvLogger (HEADER, set_output_file(), write_sample(), close()).
    Imports: csv, os, time.

[F] scanner/data_sources.py
    Role: the two interchangeable data sources behind the read loop.
    Key symbols:
      - SerialManager: live pyserial port; supports_commands = True.
      - CsvReplaySource: replays a recorded CSV as if live;
        supports_commands = False; adds time-scrub methods (position, total,
        window_lines(), set_position()).
    Both expose the SAME minimal interface: is_connected, in_waiting,
      readline(), reset_input_buffer(), write(), disconnect(), close(), and an
      optional on_change callback.
    Imports: serial, serial.tools.list_ports, os, csv, time, collections.deque,
      scanner.config (MAX_POINTS, REPLAY_DEFAULT_SPEED).

[G] scanner/state.py
    Role: THE central hub — all mutable runtime state + sample ingestion.
    Key symbol: ScannerState. Holds:
      - live ring buffers: timestamps, sensor1 (R_p), sensor2 (L),
        crack_times, crack_mags, crack_sizes (all deque, maxlen=MAX_POINTS).
      - control flags: paused, write_to_file_enabled.
      - readout text + latest non-zero values.
      - view flags: right_x_mode ("RP"/"TIME"), right_plot_auto_time_fallback,
        crack_y_mode ("mag"/"crack_size"), scrub_velocity, xy_start_index.
      - snapshot cache: snap_time, snap_rp, snap_l, snap_crack_times,
        snap_crack_mags, snap_crack_sizes (the exact currently-plotted window).
      Methods: reset(), ingest_sample(), ingest_crack_event(),
        stage_command_exchange(), consume_pending_command_exchange().
    Imports: numpy, time, collections.deque, scanner.config
      (MAX_POINTS, RECENT_FADE_POINTS), scanner.parsing (parse_crack_event).

[H] scanner/snapshot.py
    Role: render the four live plots as journal-quality vector PDFs.
    Key symbol: make_snapshot(state, out_root, on_status=print) -> list[str].

[I] LDC SCANNER V6.py  (the runnable entry file; NOT part of the package)

5. RUNTIME OBJECTS (created once in Section 7 of the entry file)
--------------------------------------------------------------------
serial_mgr    = SerialManager(BAUDRATE)     # the live serial source (persistent)
csv_logger    = CsvLogger(CSV_FILE)         # output CSV writer
state         = ScannerState()              # the central state hub
replay_source = None                        # a CsvReplaySource once a replay starts
source        = serial_mgr                  # POINTER to the ACTIVE data source

`source` is the key indirection: the read loop always drains `source`, which is
reassigned between `serial_mgr` and the active `replay_source` when the user
switches mode. Both sources' on_change callback is set to
set_connection_ui_state.

--------------------------------------------------------------------
6. LIVE DATA PIPELINE (the per-frame path; happens every 50 ms)
--------------------------------------------------------------------
A QTimer fires update() every 50 ms. Ordered flow:

(1) Hardware/CSV -> source (serial_mgr OR replay_source)
(2) update() calls read_serial()
(3) read_serial(): if not state.paused, while source.in_waiting: read
    source.readline() and pass each line to consume_serial_line()
(4) consume_serial_line(line):
      - append raw text to state.incoming_history (+ append_incoming_line UI)
      - extract_reject_reason(line) -> state.reject_reason
      - state.ingest_crack_event(line)   [uses parse_crack_event]
      - parse_serial_line(line) -> (t, rp, l, mag, width, crack_x, crack_size)
      - state.ingest_sample(...)
(5) state.ingest_sample():
      - append t -> timestamps, rp -> sensor1, l -> sensor2
      - if write_to_file_enabled: csv_logger.write_sample(...) -> CSV file
      - update latest non-zero mag/width/crack_size + readout_text
(6) Back in update(): read buffers into numpy arrays (x_all, y1_all=R_p,
    y2_all=L); compute crack arrays; apply DISPLAY_LAG_POINTS trimming.
(7) update() caches the visible window into
      state.snap_time / snap_rp / snap_l / snap_crack_* (for Snapshot).
(8) update() redraws the three views:
      - 3D surface: build_surface_data(time, R_p, L) -> mesh + trace + head
      - upper-right plot: choose Phase Space (L vs R_p) if has_usable_rp(R_p),
        else Time Trace (L vs t); also honors state.right_x_mode; draws the
        red->white recent-tail gradient (length RECENT_FADE_POINTS).
      - crack plot: vertical stems of mag or crack_size vs time; x-axis links to
        the upper plot when the upper plot is in a time x-mode.
      - update readout_label + average_label text.

--------------------------------------------------------------------
7. DATA-SOURCE ABSTRACTION & MODE SWITCHING (Live Serial vs CSV Replay)
--------------------------------------------------------------------
- current_mode() reads the mode combo ("serial" | "csv").
- Live Serial: toggle_connection() calls serial_mgr.connect()/disconnect();
  source = serial_mgr.
- CSV Replay: start_replay() builds CsvReplaySource(path, speed), sets
  source = replay_source, calls state.reset(), replay_source.start();
  stop_replay() disconnects it.
- on_mode_changed() disconnects the other source and repoints `source`.
- Any source hardware error auto-disconnects and fires on_change ->
  set_connection_ui_state() (updates widget enabled/visibility + status label).

Replay-only TIME SCRUBBING (Left/Right arrow keys):
  keyPressEvent -> scrub_replay(direction, accelerating):
    - accelerates step by REPLAY_SCRUB_ACCEL up to REPLAY_SCRUB_MAX_STEP
    - source.set_position(new_index)
    - rebuild_from_replay(): state.reset(); re-ingest source.window_lines()
      via consume_serial_line(..., log=False, show_incoming=False); the next
      update() repaints from the rebuilt buffers.
  keyReleaseEvent resets scrub_velocity.

--------------------------------------------------------------------
8. SNAPSHOT EXPORT FLOW
--------------------------------------------------------------------
Snapshot button.clicked -> take_snapshot() (entry file)
  -> make_snapshot(state, SNAPSHOT_ROOT, on_status=_snapshot_status)
       - reads state.snap_time / snap_rp / snap_l / snap_crack_*
       - build_surface_data(...) for the 3D panel
       - matplotlib renders 5 PDFs into Snapshots/Snapshot <timestamp>/:
           phase_space.pdf, time_trace.pdf, surface_3d.pdf, crack_events.pdf,
           combined.pdf
       - returns list of paths; _snapshot_status() writes progress to
         connection_status_label + stdout.

--------------------------------------------------------------------
9. USER-INTERACTION HANDLER CLUSTERS (entry file) — what each touches
--------------------------------------------------------------------
- Connection controls: refresh_ports, current_mode, replay_active, browse_csv,
  start_replay, stop_replay, toggle_connection, on_mode_changed,
  set_connection_ui_state  <-> serial_mgr / replay_source / source + many
  connection widgets + connection_status_label.
- Serial console: send_serial_command (source.write + collect responses),
  append_incoming_line  <-> serial_command_input / serial_response_box /
  incoming_line_box + state.
- CSV write: write_toggle_changed (-> state.write_to_file_enabled),
  apply_csv_filename (-> csv_logger.set_output_file).
- Axis toggles: set_right_x_mode/toggle_right_x_mode (plot_xy title/labels +
  state.right_x_mode) via ToggleAxisItem on the x-axis;
  set_crack_y_mode/toggle_crack_y_mode (crack_plot label + state.crack_y_mode)
  via ToggleAxisItem on the crack y-axis.
- Keyboard: keyPressEvent (Space=reset all plots+state, P=pause, F=toggle CSV
  write, 1/2/3=3D view presets, Left/Right=scrub), keyReleaseEvent.
- Lifecycle: close_resources() on app quit -> csv_logger.close(),
  serial_mgr.close(), replay_source.close().
