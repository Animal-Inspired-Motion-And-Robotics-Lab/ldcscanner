Use the appropriate branch depending on what you want to do:

To stream data from the robot or a .csv file, logging data to a .csv and outputting visuals, use
dual-stream `LDC SCANNER V6` for real-time logging from the robot, visualization, visual outputs from a logged .csv file
dual-stream `SNR_Interactive_Analysis` for visualizations of processed SNR data for the paper

To convert raw data into per-crack SNR values by manually selecting cracks and computing SNR, use
snr-analysis `Scanimator V4`
