Use this branch to produce SNR results, like the ones in the ldcscanner\outputs folder.

The only script that should be used here is called Scanimator V4. Use this to process .csv files that were generated by LDC SCANNER V5/V6 in the dual-streams branch.

Scanimator V4 allows the user to manually process logged data, including highlighting crack/notch signals. Data rotation and data smoothing are also supported, but usually handled on-board the robot.
